# Кот-повар (`cat_chef`) — спрайты

- Источник: архив `cat_chef_sprite_assets.zip`.
  Исходные описание и README без изменений: `art/characters/cat_chef/original/`.
- Атлас `cat_chef_atlas_64px.png`: 256×256 px, сетка 4×4, ячейка 64×64, PNG RGBA с прозрачностью.
- Отдельные кадры: 16 файлов `frames/NN_<id>.png` 64×64 RGBA. NN — номер ячейки атласа
  (слева направо, сверху вниз); каждый кадр совпадает со своей ячейкой пиксель в пиксель.
- Описание кадров и групп: `cat_chef.json` (формат 1, см. `assets/README.md`).
- Пиксели не изменялись: PNG скопированы из архива байт в байт, изменены только имена файлов
  (исходное имя каждого кадра — в поле `source_file`).

## Группы кадров

| Группа | Кадры | Кадр/с | В игре | Статус |
|---|---|---|---|---|
| `idle` | idle_grumpy, stern_arms_crossed | 2 | цикл | **черновик**: Предварительная группа из разных сюжетных поз (по README), а не фазы одного цикла |
| `greet` | playful_greeting, happy_sushi_tray | 2 | один раз | **черновик**: Предварительная группа из разных сюжетных поз (по README), а не фазы одного цикла |
| `prepare_sushi` | slice_salmon_1, slice_salmon_2, arrange_sushi | 4 | цикл | **черновик**: Предварительная группа (README): цикл приготовления суши не проверен в игре |
| `serve_sushi` | happy_sushi_tray, present_sushi | 2 | один раз | **черновик**: Предварительная группа из разных сюжетных поз (по README), а не фазы одного цикла |
| `eat` | taste_sushi | 1 | один раз | одиночная поза |
| `react_angry` | angry_shout, sit_resting | 2 | один раз | **черновик**: Предварительная группа из разных сюжетных поз (по README), а не фазы одного цикла |
| `move_with_tray` | walk_right_tray_1, walk_right_angled, walk_right_tray_2 | 3 | цикл | **черновик**: README: черновой набор движения, нужно просмотреть в Pygame |
| `back_view` | back_view | 1 | цикл | одиночная поза |

## Заметки из исходников

- Один персонаж на отдельном спрайт-листе.
- Шахматный фон был удалён; итоговый атлас — RGBA с альфа-прозрачностью.
- Все кадры приведены к 64×64 и выровнены по нижней точке.
- Большинство кадров — сюжетные позы, не все группы являются полноценными плавными циклами.
- Перед подключением проверьте читаемость суши и силуэта на масштабе 64×64.
