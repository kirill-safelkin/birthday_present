# Хомяк-чиновник (`hamster_official`) — спрайты

- Источник: архив `hamster_clerk_sprite_assets.zip`, исходный идентификатор `hamster_clerk`.
  Исходные описание и README без изменений: `art/characters/hamster_official/original/`.
- Атлас `hamster_official_atlas_64px.png`: 256×256 px, сетка 4×4, ячейка 64×64, PNG RGBA с прозрачностью.
- Отдельные кадры: 16 файлов `frames/NN_<id>.png` 64×64 RGBA. NN — номер ячейки атласа
  (слева направо, сверху вниз); каждый кадр совпадает со своей ячейкой пиксель в пиксель.
- Описание кадров и групп: `hamster_official.json` (формат 1, см. `assets/README.md`).
- Пиксели не изменялись: PNG скопированы из архива байт в байт, изменены только имена файлов
  (исходное имя каждого кадра — в поле `source_file`).

## Заметки из исходников

- Атлас технически нормализован до ячеек 64×64 px.
- Исходная генерация содержала 5×4 композицию; 16 выбранных поз перенесены в 4×4 атлас.
- Наборы кадров являются преимущественно сюжетными позами, а не полноценными длинными циклами.
- Группа walk_side_papers — предварительная пара боковых поз; проверить визуально в Pygame.
