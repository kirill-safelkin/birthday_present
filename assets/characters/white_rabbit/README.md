# Белый Кролик (`white_rabbit`) — спрайты

- Источник: архив `white_rabbit_sprite_assets.zip`.
  Исходные описание и README без изменений: `art/characters/white_rabbit/original/`.
- Атлас `white_rabbit_atlas_64px.png`: 256×256 px, сетка 4×4, ячейка 64×64, PNG RGBA с прозрачностью.
- Отдельные кадры: 16 файлов `frames/NN_<id>.png` 64×64 RGBA. NN — номер ячейки атласа
  (слева направо, сверху вниз); каждый кадр совпадает со своей ячейкой пиксель в пиксель.
- Описание кадров и групп: `white_rabbit.json` (формат 1, см. `assets/README.md`).
- Пиксели не изменялись: PNG скопированы из архива байт в байт, изменены только имена файлов
  (исходное имя каждого кадра — в поле `source_file`).

## Группы кадров

| Группа | Кадры | Кадр/с | В игре | Статус |
|---|---|---|---|---|
| `idle` | idle_front | 2 | цикл | одиночная поза |
| `check_watch` | checks_watch_happy, confused_watch, annoyed_watch | 3 | цикл | **черновик**: JSON помечен в README как черновая схема действий; в группе разные сюжетные позы |
| `talk_or_point` | hurries_pointing, confident_point | 3 | цикл | **черновик**: JSON помечен в README как черновая схема действий; в группе разные сюжетные позы |
| `panic` | panics_watch, panic_gasp | 5 | один раз | **черновик**: JSON помечен в README как черновая схема действий; в группе разные сюжетные позы |
| `run_right` | run_right_1, run_right_2, run_right_3, run_right_4 | 10 | цикл | **черновик**: README: беговой цикл нужно проверить в игре и при необходимости заменить кадры |
| `rest` | exhausted_rest, idle_seated | 2 | цикл | **черновик**: JSON помечен в README как черновая схема действий; в группе разные сюжетные позы |
| `read_schedule` | reads_schedule | 1 | цикл | одиночная поза |
| `back_view` | back_view | 1 | цикл | одиночная поза |
