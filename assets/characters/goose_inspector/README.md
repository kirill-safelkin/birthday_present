# Гусь-инспектор (`goose_inspector`) — спрайты

- Источник: архив `goose_inspector_sprite_assets.zip`.
  Исходные описание и README без изменений: `art/characters/goose_inspector/original/`.
- Атлас `goose_inspector_atlas_64px.png`: 256×192 px, сетка 4×3, ячейка 64×64, PNG RGBA с прозрачностью.
- Отдельные кадры: 12 файлов `frames/NN_<id>.png` 64×64 RGBA. NN — номер ячейки атласа
  (слева направо, сверху вниз); каждый кадр совпадает со своей ячейкой пиксель в пиксель.
- Описание кадров и групп: `goose_inspector.json` (формат 1, см. `assets/README.md`).
- Пиксели не изменялись: PNG скопированы из архива байт в байт, изменены только имена файлов
  (исходное имя каждого кадра — в поле `source_file`).

## Кадры

| Ячейка | id | Описание |
|---|---|---|
| 0 | `idle` | Нейтральная поза |
| 1 | `inspect` | Строго изучает бумаги |

| 3 | `question` | Растерянность |
| 4 | `stamp` | Ставит печать |
| 5 | `reject` | Отклоняет формуляр |
| 6 | `approve` | Одобряет формуляр |
| 7 | `write` | Делает запись |
| 8 | `read` | Читает документ |
| 9 | `profile_right` | Профиль вправо |
| 10 | `profile_left` | Профиль влево |

## Заметки из исходников

- Компактный комплект из 12 поз для второстепенного NPC.
- Большинство поз — одноразовые сюжетные действия, не полноценные циклы. Для ходьбы доступны только одиночные профильные позы; при необходимости добавить цикл позже.
- Атлас RGBA с прозрачным фоном; preview-файл содержит только шахматную подложку и номера.
