# Алиса (`alice`) — спрайты

- Источник: архив `alice_sprite_sheet_fixed.zip`.
  Исходные описание и README без изменений: `art/characters/alice/original/`.
- Атлас `alice_atlas_64px.png`: 256×512 px, сетка 4×8, ячейка 64×64, PNG RGBA с прозрачностью.
- Отдельные кадры: 28 файлов `frames/NN_<id>.png` 64×64 RGBA. NN — номер ячейки атласа
  (слева направо, сверху вниз); каждый кадр совпадает со своей ячейкой пиксель в пиксель.
- Пустые ячейки атласа: 22, 23, 27, 31.
- Описание кадров и групп: `alice.json` (формат 1, см. `assets/README.md`).
- Пиксели не изменялись: PNG скопированы из архива байт в байт, изменены только имена файлов
  (исходное имя каждого кадра — в поле `source_file`).
- Описания кадров составлены по именам групп из исходного `alice.json` (в нём описаний нет).

## Заметки из исходников

- README архива называет весь лист черновиком: «Алиса — нормализованный спрайт-лист (черновик)».
- Atlas normalized to transparent 64x64 cells. Side-walk rows were replaced with isolated, evenly sampled frames from a separate directional walk generation, ensuring left/right faces opposite directions. Vertical gait from the generated source remains subtler and should be reviewed at game scale.
