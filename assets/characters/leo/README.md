# Лео (`leo`) — спрайты

- Источник: архив `leo_sprite_assets.zip`.
  Исходные описание и README без изменений: `art/characters/leo/original/`.
- Атлас `leo_atlas_64px.png`: 256×256 px, сетка 4×4, ячейка 64×64, PNG RGBA с прозрачностью.
- Отдельные кадры: 16 файлов `frames/NN_<id>.png` 64×64 RGBA. NN — номер ячейки атласа
  (слева направо, сверху вниз); каждый кадр совпадает со своей ячейкой пиксель в пиксель.
- Описание кадров и групп: `leo.json` (формат 1, см. `assets/README.md`).
- Пиксели не изменялись: PNG скопированы из архива байт в байт, изменены только имена файлов
  (исходное имя каждого кадра — в поле `source_file`).

## Группы кадров

Групп нет: это набор отдельных сюжетных поз, а не анимаций.

## Заметки из исходников

- Набор сюжетных поз и реакций для младенца, а не 16 последовательных кадров одной анимации. Лист собран выделением основных силуэтов из генерации и нормализацией в общие ячейки 64×64.
