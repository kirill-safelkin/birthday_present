# Ресурсы игры

Здесь лежит только то, что игра загружает во время работы. Концепты, референсы и
исходники редакторов (`.aseprite` и т. п.) хранятся в `art/`, игра их не читает.
Пути к ресурсам указываются относительно папки проекта (`config.PROJECT_DIR`).

## Структура

Папки создаются вместе с первым файлом в них:

```text
characters/<имя>/   листы спрайтов персонажей и их разметка
tilesets/           плитки для локаций
maps/               карты локаций
props/              предметы и объекты на локациях
backgrounds/        фоны
ui/                 рамки, иконки, курсор
fonts/              пиксельный шрифт с кириллицей и файл его лицензии
audio/music/, audio/sfx/
```

## Правила для спрайтов

- PNG RGBA с настоящим прозрачным фоном. Предпросмотры с шахматной подложкой,
  номерами и сеткой — не игровые ресурсы, они лежат в `art/`.
- Кадры одного листа одинакового размера и лежат в сетке атласа; ячейки
  нумеруются слева направо, сверху вниз. Какая ячейка к какой позе и группе
  относится, говорит манифест, а не порядок строк.
- Ноги персонажа стоят у нижнего края ячейки, по центру: позиция `Character` — точка
  под ногами.
- Размер кадра не угадывается: он записан в манифесте и сверяется с изображением.
  Концепт-листы с подписями, палитрами и несколькими персонажами листами спрайтов
  не являются.
- Пиксели утверждённых кадров не меняются: импорт копирует PNG как есть,
  масштабирование делается только при выводе на экран.
- Спрайты персонажей сейчас 64×64. Размер, в котором они будут показаны на холсте
  320×180, ещё не выбран: для сравнения есть галерея спрайтов (клавиша P на экране
  проверки, размеры 24–64 пикселя).

## Спрайты персонажа

```text
characters/<id>/
  <id>.json             манифест (формат ниже)
  <id>_atlas_64px.png   атлас всех кадров
  frames/NN_<кадр>.png  отдельные кадры; NN — номер ячейки атласа
  README.md             технические сведения: источник, сетка, группы, черновики
```

Манифест, формат 1 (полностью проверяется в `game/graphics/sprite_manifest.py`):

```json
{
  "format": 1,
  "id": "alice",
  "display_name": "Алиса",
  "frame_size": [64, 64],
  "atlas": {"file": "alice_atlas_64px.png", "columns": 4, "rows": 8},
  "frames": [
    {"id": "walk_down_1", "index": 4, "file": "frames/04_walk_down_1.png",
     "description": "Идёт, смотрит вниз, фаза 1 из 4", "source_file": "frames/walk_down/000.png"}
  ],
  "animations": {
    "walk_down": {"frames": ["walk_down_1", "walk_down_2"], "fps": 8, "loop": true,
                  "draft": true, "draft_reason": "почему группа черновая"}
  },
  "poses": {"псевдоним": "id кадра"},
  "source": {"archive": "…", "id": "…", "manifest": "art/characters/<id>/original/…"},
  "notes": ["…"]
}
```

- `id` совпадает с именем папки; идентификаторы — `snake_case`.
- Каждый отдельный кадр совпадает со своей ячейкой атласа пиксель в пиксель.
- Группы (`animations`) — это кадры, которые можно проиграть подряд. `draft: true`
  значит, что непрерывность группы не подтверждена (группа собрана из разных
  сюжетных поз или помечена черновой в исходниках); причина — в `draft_reason`.
- `poses`, `source`, `notes` и `source_file` необязательны. Псевдоним позы и id кадра
  принимает `CharacterSprites.pose()` — так неподвижный персонаж берёт кадр эмоции.
- Кадры не отражаются: если персонаж несимметричен (скипетр, поднос), для взгляда
  влево и вправо нужны свои кадры, а не зеркальная копия.
- Исходные JSON и README из архивов хранятся без изменений
  в `art/characters/<id>/original/`.
- Имена файлов и идентификаторы — латиница, нижний регистр, `snake_case`:
  `alice`, `leo`, `chuchmek`, `white_rabbit`, `cat_chef`, `goose_inspector`,
  `hamster_official`, `great_cake`, `strawberry`.
