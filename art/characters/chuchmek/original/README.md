# Чучмек — спрайт-лист

- `chuchmek_atlas_64px.png`: прозрачный атлас 256×256 px, сетка 4×4, ячейка 64×64.
- `frames/`: 16 кадров по отдельности, каждый PNG 64×64.
- `chuchmek.json`: расположение кадров и предварительные группы анимаций.
- `chuchmek_atlas_preview.png`: увеличенное превью с сеткой и номерами.
- `chuchmek_source_sheet.png`: исходная генерация для сравнения.

## Порядок сетки

Строка 1: спокойная поза, подмигивание, любопытный взгляд, уверенность с планшетом.
Строка 2: четыре позы разговора/жестикуляции.
Строка 3: растерянность, паника, руки вверх, самодовольное подмигивание.
Строка 4: четыре боковые позы бега вправо.

## Важно

Атлас технически нормализован, но качество самой анимации — художественный вопрос. Проверьте последовательность `talk` и `run_right` в игре; похожие позы могут потребовать отдельной перегенерации или ручной доработки.
