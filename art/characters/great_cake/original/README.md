# Тортище — спрайт-ресурсы

Утверждённый образ: величественный, слегка угрожающий, но комичный торт-монстр с золотой короной, клубникой, розово-кремовыми ярусами, королевской бордовой накидкой с меховой окантовкой и скипетром в виде десерта.

## Содержимое

- `great_cake_atlas_64px.png` — игровой атлас 256×256 px, 4×4 ячейки по 64×64.
- `frames/` — 16 отдельных кадров PNG 64×64 на прозрачном фоне.
- `great_cake.json` — манифест с кадрами, координатами исходных кропов и предварительными группами поз.
- `great_cake_atlas_preview.png` — увеличенный предпросмотр с шахматной подложкой, сеткой и номерами кадров.
- `great_cake_source_sheet.png` — полное исходное изображение.
- `source_frames/` — изолированные исходные кадры высокого разрешения до уменьшения в 64×64.

## Порядок кадров

0. `idle_front` — величественная фронтальная поза со скипетром.
1. `wink_front` — фронтальная поза с подмигиванием.
2. `back_cape` — вид сзади, хорошо видна королевская накидка.
3. `profile_right` — профиль вправо.
4–7. `reaction` — крик, самодовольный взгляд, гневный жест и скрещённые руки.
8–11. `walk_right_01`…`walk_right_04` — боковые позы, направленные вправо.
12–15. `walk_left_01`…`walk_left_04` — боковые позы, направленные влево.

## Важные замечания для импорта

- Идентификатор: `great_cake`; отображаемое имя: «Тортище».
- Размер runtime-кадра 64×64 выбран для совместимости с текущей структурой `assets/characters/`.
- Исходные кропы высокого разрешения сохранены отдельно: не удаляйте их при импорте.
- Анимационные группы в JSON — предварительное соответствие поз. Перед зацикливанием `walk_left` и `walk_right` проверьте визуально, что переключение кадров не выглядит дёрганым. Это прежде всего набор поз, а не гарантированно идеальные циклы движения.
- Не отражайте спрайт по горизонтали: скипетр и накидка создают асимметрию. Используйте отдельные кадры левого и правого направления.
- Исходный лист сохранён без изменений. Нормализованные кадры уменьшены до 64×64 с сохранением пропорций и без предварительного увеличения в игре.
