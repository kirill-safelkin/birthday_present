# Алиса — нормализованный спрайт-лист (черновик)

- `alice_atlas_64px.png`: прозрачный PNG-атлас 256×512 px, сетка 4×8, ячейки 64×64 px.
- `alice_atlas_preview.png`: увеличенный предпросмотр на шахматном фоне.
- `frames/`: отдельные PNG-кадры, разложенные по анимациям.
- `alice.json`: строки/столбцы атласа, число кадров, FPS и цикличность.

Персонажи вырезаны по основному альфа-компоненту, очищены от линий исходной сетки и размещены в одинаковых ячейках с выравниванием по нижней точке. Четыре направления idle описаны отдельно: они не должны проигрываться как один вращающийся цикл. Боковые циклы ходьбы заменены отдельными кадрами, смотрящими в разные стороны. Кадры ходьбы вниз/вверх всё ещё визуально тонкие и являются черновыми, а не окончательным художественным результатом.
