# Исходники и концепты

Концепт-арт, референсы и рабочие файлы редакторов. Игра эту папку не читает.
Готовые для игры PNG кладутся в `assets/` по правилам из `assets/README.md`.

```text
characters/<id>/
  original/                 исходные JSON и README из архива, без изменений
  original/source_frames/   кропы кадров высокого разрешения до уменьшения в 64×64 (если есть в архиве)
  <id>_atlas_preview.png    увеличенный предпросмотр с шахматной подложкой и номерами
  <id>_source_sheet.png     исходная генерация (только локально, в Git не попадает)
```

Тяжёлые файлы (больше 1–2 МБ) в Git не коммитить. Исходные генерации персонажей
(`*_source_sheet.png`, `*_with_checkerboard.png`, по 2–3 МБ) исключены в `.gitignore`:
они лежат здесь только локально, а оригиналы остаются в архивах.
